## 🚀 Instalación rápida

```bash
# Clonar e instalar
git clone https://github.com/Ignacia22/libreria-angular.git
cd libreria-angular
npm install

# Ejecutar
ng serve
```

Abrir [http://localhost:4200](http://localhost:4200)
